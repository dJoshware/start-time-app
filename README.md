# Start Time App

A tool for UPS hub employees and supervisors to stay on the same page about
daily start times. Supervisors post start times and announcements per sort
and area; employees open the app (or the installed PWA) and immediately see
their next scheduled start time, no more guessing or waiting on a text
chain.

**Live site:** [start-time-app.vercel.app](https://start-time-app.vercel.app)

## What it does

- **Self-registration** — new users register through a guided form
  (location/hub, sort, role, area) instead of waiting on an admin. The
  browser's location suggests the nearest hub automatically.
- **Strict role separation** — employees can only self-register as
  employees. Supervisor access requires an invite code generated by an
  existing supervisor at that hub, so no one can grant themselves elevated
  access.
- **Multi-hub** — built to support any UPS hub, not just one building. Each
  location has its own sorts, areas, start times, and announcements.
- **Supervisor panel** — post announcements, set start times for the coming
  week, manage employee accounts, and generate supervisor invite codes.
- **Installable PWA** — add it to your home screen for an app-like
  experience with push notifications when start times or announcements
  change.

## Tech stack

- [Next.js](https://nextjs.org) (App Router)
- [Supabase](https://supabase.com) (Postgres)
- [web-push](https://github.com/web-push-libs/web-push) for push notifications
